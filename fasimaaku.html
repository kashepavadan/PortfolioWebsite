How searching works

Narrow search (default) finds exact matches: an English meaning, or a whole Fasimāķu word. Broad search also matches part of a Fasimāķu word, or any English text in a word's explanation. You can type Fasimāķu in plain ASCII and it will be converted before searching. Use ← and → to step through words.

Script Converter

Type with ASCII digraphs and it converts as you go: nh → ñ, t' → ţ, k' → ķ, th → ð, sh → š, ii → ī, aa → ā, ee → ē, uu → ū, "quotes" → «quotes».
